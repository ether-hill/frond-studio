# Object Viewer — 3D model credits

Every object is a **Poly Haven** (https://polyhaven.com) model, released under
**CC0 1.0** (public domain, https://creativecommons.org/publicdomain/zero/1.0/).
No attribution is required, but the author and a Poly Haven link are shown on
screen and listed here as a courtesy. Each model ships as glTF + a shared `.bin`
and 1k PBR textures under its own folder.
